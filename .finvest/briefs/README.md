# Brief templates

A dispatch is 3–5 lines and ends with "Follow `.finvest/briefs/<role>.md`". The template holds
everything that is the same every time; the dispatch gives only what is task-specific (task id, PR,
worktree, anything unusual). Owner: the Scrum Master.

| File | Read by |
|---|---|
| `common.md` | every agent, first |
| `owner.md` | po, pm, software architect, ai architect (artifact table, consult mode) |
| `dev.md` | fe-dev, be-dev, ai-engineer |
| `lead.md` | tech lead |
| `tester.md` | fe-tester, be-tester |
