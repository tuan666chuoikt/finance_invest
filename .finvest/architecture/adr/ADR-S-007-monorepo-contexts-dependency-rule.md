# ADR-S-007 — Monorepo, bounded contexts as packages, layering enforced by import-linter
Status: Accepted · 2026-10-15

## Decision
Layout and context → package map in codebase.md §1–3. Each Python package has `domain/ application/ adapters/
infrastructure/`; the dependency rule (domain ← application ← adapters/infrastructure ← api/cli;
`finvest_rules` imports nothing; `finvest_analytics` never imports `finvest_crawler`) is a test in the kernel via
import-linter. The only entry for market data is the `MarketDataSource` port. Contracts live in
`packages/contracts` and are regenerated by `make contracts`; a dirty diff fails CI (contract drift = blocker).

## Why
Agents work in parallel on exclusive file sets; a mechanical rule catches the "import the adapter directly" shortcut
before a human reviews it. The proposal's layout (docs/03 §4) is kept so docs and code agree.
